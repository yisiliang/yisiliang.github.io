01 / MOTIVATION

一个词的意思，需要向其他词借信息

看句子“小王把书交给小李，因为他明天要用”。“他”指谁，要结合上下文判断。单独给“他”一个固定向量，无法表达这句话中的具体指代。我们希望每个位置都能参考其他位置，把相关信息融入自己的表示。

可以先把Attention想成一次可学习的信息检索：当前词提出查询，其他词提供匹配线索和可取回的信息；匹配程度决定混合比例。它不是检索某个外部数据库，而是对模型内部的向量做运算。输出还是向量，并不是一句“他指小李”的解释。

循环网络通常沿句子位置递推：后一个隐藏状态要等待前一个。Self-Attention可以让同一层的所有位置一起计算匹配，并让远处位置直接交换信息。但更短的计算路径不保证模型一定学对，也不代表整个训练没有顺序依赖。

原文定位：§1—2，第1—2页讨论顺序计算与长距离依赖。本文的中文指代例子是教学构造。

02 / REPRESENTATION

先把文字变成能计算的行向量

模型通常先将文本切成token。token可以是一个词、一个子词或其他片段，不能默认一个汉字或一个单词就是一个token。token编号只用于查表，本身不是语义坐标。

设词表大小为v，表示宽度为d，学习的嵌入表E有v行、d列。编号7取出E的第7行，得到长度d的向量。n个token组成X，形状为n×d；每行对应一个位置，每列是表示的一个分量。这些分量通常不能逐个命名成“人物”“时间”等人工标签。

教学简化：n=3，d=2，暂不加入位置编码
X = [[1, 0],       # 位置0
     [0, 1],       # 位置1
     [1, 1]]       # 位置2
形状：3×2；每行是一个位置的向量。

嵌入参数由训练更新。后面层的输入通常已经是带有上下文的隐藏表示，不再是最初的词表查表结果。“同一token在不同上下文有不同表示”，主要来自位置与逐层的信息交换。

原文定位：§3.4，第5页。下文全部小矩阵独立于论文训练数据。

03 / LEARNED PROJECTIONS

Q是查询，K用于匹配，V提供被汇总的内容

检索比喻里，Q像“我现在需要什么信息”，K像“我能以什么特征被匹配”，V像“匹配后提供什么信息”。真正的实现是三个学习的线性投影：

Q = X WQ     K = X WK     V = X WV
X: n×d       WQ、WK: d×dk       WV: d×dv
Q、K: n×dk   V: n×dv

这里的“学习”表示WQ、WK、WV最初是参数，训练根据预测误差调整它们；不是程序员手写“Q代表主语、K代表宾语”。三个投影共享输入，却可以为匹配与传递信息保留不同特征。Q和K宽度相同才能点乘，V的宽度dv可以不同。

我们的教学例子取WQ和WK为2×2单位矩阵，WV为对角矩阵diag(2,1)。因此Q=K=X，V=[[2,0],[0,1],[2,1]]。例如第三行[1,1]乘WV得到[2,1]：第一分量乘2，第二分量保留。

Self-Attention中的Q、K、V来自同一组位置。Cross-Attention则让查询来自目标序列、K和V来自源序列；此时Q有m行，K和V有n行，两个序列长度可以不同。

原文定位：§3.2.1—3.2.3，第4—5页。用单位矩阵只是为了手算，训练中的参数不被限制为单位矩阵。

04 / WORKED EXAMPLE

一次Attention：打分、归一化、取信息

Attention(Q,K,V) = softmax(Q Kᵀ / √dk) V
一般形状：Q(m×dk) · Kᵀ(dk×n) → 分数(m×n)
逐行softmax后仍为m×n，再乘V(n×dv) → 输出(m×dv)。

当前教学例子m=n=3，dk=dv=2。每个分数是一个查询与一个键的点积：第一行查询[1,0]对第三行键[1,1]的分数为1×1+0×1=1。把所有组合一起算：

QKᵀ = [[1, 0, 1],
        [0, 1, 1],
        [1, 1, 2]]
S = QKᵀ / √2
  ≈ [[0.707107, 0,        0.707107],
     [0,        0.707107, 0.707107],
     [0.707107, 0.707107, 1.414214]]
A = softmax(S)，对每行分别算
  ≈ [[0.401112, 0.197776, 0.401112],
     [0.197776, 0.401112, 0.401112],
     [0.248255, 0.248255, 0.503490]]
O = AV
  ≈ [[1.604448, 0.598888],
     [1.197776, 0.802224],
     [1.503490, 0.751745]]

拆开第一行：输出第一分量=0.401112×2+0.197776×0+0.401112×2≈1.604448；第二分量=0.401112×0+0.197776×1+0.401112×1≈0.598888。匹配使用K，汇总使用V：输出不是“选中第三个词”，而是几行内容的加权组合。

如果三个V完全相同，改变权重也不改变这一层的加权输出。这已经说明不能只看权重就断言“哪个输入导致最终答案”。后面还有输出投影、其他头、残差和多层变换。

固定K和V，调整q两个分量，观察权重与输出。默认值对应上面的第一行；计算独立于任何已训练模型。

05 / SCALING AND SOFTMAX

为什么除以√dk，又为什么使用softmax

点积把dk项相加。如果各分量近似独立、均值为0、方差为1，点积方差为dk，标准差随√dk增长。除以√dk使这一简化假设下的分数方差回到1。这不是强制向量长度为1，也不是余弦相似度；学习后的分量未必满足这些假设。

softmax把一行任意实数变成正权重，并令它们之和为1。令一行分数为s₀…sₙ₋₁，其第j个权重为exp(sⱼ)/Σexp(sₖ)。它比较的是同一查询面对所有键的相对分数，不是对每个分数独立求概率。

教学计算：s=[0.707107,0,0.707107]
exp(s)≈[2.028115,1,2.028115]
总和≈5.056230 → [0.401112,0.197776,0.401112]
稳定实现：exp(sⱼ-max(s)) / Σexp(sₖ-max(s))
一行全部加100后，权重不变；减最大值避免指数溢出。

分数过大时softmax可能极度尖锐。对两个分数[0,10]，权重约[0.000045,0.999955]；对[0,1]则约[0.268941,0.731059]。接近0或1时，对应的局部梯度可能很小。缩放缓和随维度增长的这一风险，并不保证所有训练都稳定。

原文定位：§3.2.1与脚注4，第4页；具体数字是教学计算。

06 / CAUSALITY

Decoder训练时，不能提前看见答案

预测第二个目标token时，只能用它之前的目标token。如果训练时让当前位置读取后面的正确答案，模型可以走捷径；真正生成时未来token尚不存在，这条路径无法使用。

M = [[0, -∞, -∞],
     [0,  0, -∞],
     [0,  0,  0]]          # 3×3
Acausal = softmax(S+M)
        ≈ [[1,        0,        0],
           [0.330238, 0.669762, 0],
           [0.248255, 0.248255, 0.503490]]

mask加在softmax之前，非法连接变成−∞，指数为0。第一行即使认为第三个键很匹配，也必须只看位置0。不能先softmax再直接清零而不重新归一化，否则合法权重的和可能小于1。

对角线允许读取当前位置，是因为Decoder输入已经右移一位：当前位置输入是上一个正确token，而不是当前要预测的答案。padding mask则屏蔽补齐的空白位置，用途与因果mask不同。若一行所有键都被屏蔽，直接计算softmax会出现未定义结果；实现需避免这种行或显式处理。

原文定位：§3.1，第3页及§3.2.3，第5页。

07 / MULTI-HEAD

多头：保留多组不同的匹配与信息汇总

只有一个头时，一次加权平均容易把不同来源的信息混成一份。多头先用不同投影分别计算，再把结果并排连接，最后学习如何组合。可以类比多组检索渠道，但不能保证某个头固定负责语法、另一个固定负责情绪。

headᵢ = Attention(X WQᵢ, X WKᵢ, X WVᵢ)
MultiHead(X) = Concat(head₁,…,headₕ) WO
每头投影：d×dk、d×dk、d×dv
每头输出：n×dv；拼接后：n×(h dv)
WO：(h dv)×d；最终：n×d。

看一个极小例子：X仍是三行二维向量，两个头各只有一维。头1的三个投影都取列向量[1,0]，头2都取[0,1]。头1读取第一坐标，头2读取第二坐标，dk=dv=1。第一位置在头1中q=1，键和值都是[1,0,1]；权重≈[0.422319,0.155362,0.422319]，输出≈0.844638。头2中q=0，三分数都是0；权重各1/3，值为[0,1,1]，输出2/3。

拼接得到[0.844638,0.666667]。若WO取[[1,1],[0,1]]，最终第一行是[0.844638,1.511304]。这里拼接保留了两份结果，输出投影再组合它们；不是把两个头平均成一个。这个例子使用手设投影，只为看清运算。

原文定位：§3.2.2，第4—5页。头的实际作用需要检查具体模型，不能用此教学例子代替训练结果。

08 / ORDER

能相互参考，还要知道谁在前、谁在后

在没有位置编码、没有位置相关mask的纯Self-Attention中，如果重排输入行，输出也只是对应重排。这叫置换等变：它不会凭空产生原来的顺序信息。“小王喜欢小李”和“小李喜欢小王”拥有相同的token集合，却有不同关系，因此需要把位置信息注入表示。因果mask本身也带有方向约束，但不等于完整的距离表示。

PE(pos,2i)   = sin(pos / 10000^(2i/d))
PE(pos,2i+1) = cos(pos / 10000^(2i/d))
pos：位置编号；i：坐标对编号；PE整体形状n×d。
教学取d=4，i=0,1：
PE(0) = [0,1,0,1]
PE(1) ≈ [0.841471,0.540302,0.010000,0.999950]
PE(2) ≈ [0.909297,-0.416147,0.019999,0.999800]

同一位置用不同频率的正弦和余弦编码：有的变化快，有的变化慢。如果嵌入e=[1,0,1,0]，在位置1相加得到[1.841471,0.540302,1.010000,0.999950]。不是追加两个新字段，宽度仍是4。

同一频率下，偏移一个固定距离相当于对sin/cos这一对分量作旋转，因此模型有机会利用相对位置的规律。这个代数性质不保证真实模型能处理任意长上下文。正弦编码可以计算到更大位置，但能算出不等于已经学会可靠外推。

原文定位：§3.5，第5—6页。位置编码公式和数字核验见verify.py。

09 / COMPLETE BLOCK

Attention搬来信息，FFN继续加工每个位置

Attention使不同位置交换信息。FFN对每个位置的向量分别做非线性变换，同一层各位置使用同一组参数，各层参数不同。只有线性变换连续相乘仍等效于一次线性变换；中间加入非线性，才扩展能表示的变换。

FFN(x) = ReLU(xW₁+b₁)W₂+b₂
x：1×d；W₁：d×f；b₁：f；W₂：f×d；b₂：d
教学：d=2，f=3，x=[1,-2]，偏置为0
W₁=[[1,0,1],[0,1,1]]；xW₁=[1,-2,-1]
ReLU → [1,0,0]
W₂=[[1,0],[0,1],[1,1]] → FFN(x)=[1,0]

残差把子层输出加回输入：y=x+F(x)。上述x与F(x)相加得到[2,−2]。它保留原信息的直接路径，也帮助梯度传播，不是保证无损保留每个细节。

原始块使用：LayerNorm(x + Sublayer(x))，即Post-LN。
对一个位置y的d个分量：
μ=(Σyⱼ)/d，σ²=(Σ(yⱼ-μ)²)/d
LN(y)ⱼ=γⱼ (yⱼ-μ)/√(σ²+ε)+βⱼ
μ、σ²为标量；γ、β有d个分量，均可学习。
教学y=[2,-2]，γ=[1,1]，β=[0,0]，ε=10⁻⁶
μ=0，σ²=4 → LN(y)≈[1,-1]。

归一化在每个token的特征维上计算，不是把整句话的全部token混在一起求一个均值。训练时还有dropout；为了看清形状，上面省略它。现代模型可能改变归一化位置、激活函数与位置表示，不能直接套回原始图。

原文定位：§3.1，第3页和§3.3，第5页。LayerNorm展开与小矩阵为教学补充；定义可对照Layer Normalization原论文。

10 / THE FULL MODEL

把这些步骤接成“读原文、生成译文”

Encoder的每个位置可以看源句的所有有效位置。因为翻译时整句源文本已经给定，这不算偷看目标答案。Decoder先参考已有目标前缀，再用自己的查询去读源表示：Q来自当前Decoder子层输入，K、V来自Encoder最终输出Z。

源长度n=4，目标长度m=3，d=8，单头dk=dv=2
Decoder输入D：3×8；Encoder输出Z：4×8
Q=D WQ：3×2；K=Z WK：4×2；V=Z WV：4×2
QKᵀ：3×4；Attention输出：3×2
多头拼接并投影回：3×8。

原文base配置的Encoder与Decoder各6层，d=512，8个头，每头dk=dv=64，FFN中间宽度2048。6层的结构相同，各层参数不同。它们是论文选定的配置，不是Transformer定义中不可变的常数。

最后一层Decoder隐藏状态H是m×d。乘词表输出矩阵Wo（d×v）得到m×v分数，逐行softmax给出每个位置的候选token分布。这里的softmax是在词表维上，前面的注意力softmax是在源位置或前缀位置维上；它们用途不同。

例如教学词表有3项，某位置分数为[2,1,0]，概率约[0.665241,0.244728,0.090031]。选择第一项只是最简单的贪心解码；不同解码方法会改变最终序列，不改变这个概率向量的定义。

原文定位：图1与§3.1，第3页，§3.2.3—3.4，第5页。

11 / TRAINING AND INFERENCE

训练可以一起算，生成仍要等上一个token

设正确译文是“我 喜欢 学习”。训练时知道整段答案，把目标输入右移，并对齐标签：

位置Decoder输入可见目标前缀预测标签
0<BOS><BOS>我
1我<BOS> 我喜欢
2喜欢<BOS> 我 喜欢学习
3学习<BOS> 我 喜欢 学习<EOS>

这就是teacher forcing：用真实前缀训练下一token预测。整段右移输入已经给定，所以可以在一批矩阵运算中计算多个位置；因果mask仍阻止每个位置访问未来内容。并行的是位置的计算，不是取消层与层、训练步与训练步的依赖。

教学损失（不加label smoothing）：
L = -(1/T) Σₜ log p(yₜ | y<ₜ, 源句)
T：有效目标位置数；L为标量。
若两个真实标签的预测概率为0.8、0.5：
L=-(log(0.8)+log(0.5))/2≈0.458145。
梯度通过词表输出、FFN、Attention传回投影与Embedding。

模型参数包含嵌入、Q/K/V投影、输出投影、FFN和归一化参数。某次运行的注意力权重A不是固定存储的模型参数，而是由本次输入和这些参数算出来的。训练不是给Q/K/V写人工语义，而是根据损失调整整个计算图。

推理时模型可能选错一个token，后面的前缀就偏离训练时见到的真实前缀。这是理解teacher forcing局限的入口。缓存已经计算的K/V可以减少重复计算，但这是实现优化，不会把原始自回归生成变成一次直接输出整个未知序列。

原文定位：§3，第2页、§3.1，第3页及§6.1，第8页。训练损失和缓存说明是教学补充；原文还采用label smoothing。

12 / EVIDENCE AND LIMITS

它是一篇架构与实验论文，结论要放回任务中

论文提出用注意力代替循环与卷积来承担序列交互，并在翻译与句法分析上检验。它提供实验支持，不是不可能性证明；标题也不表示整个网络只有Attention。

原文证据报告的结果能支持的结论与限制
表2，PDF第8页英德BLEU：base27.3、big28.4；英法：base38.1、big41.8。对应WMT2014测试与论文配置；不是所有任务的质量排名。
§5.2，第7页8块P100 GPU；base约12小时，big约3.5天。是该硬件与训练设置的报告，不能当作今天复现的时间承诺。
表3，第9页单头开发集BLEU24.9；8头25.8；32头25.4。这组控制计算量的变体支持多头有帮助；不支持“头越多越好”。
表3(E)，第9页学习位置嵌入25.7，正弦编码base25.8。该实验接近；没有证明正弦必然优于所有位置编码。
表4，第9页句法分析还比较不同数据规模。为迁移到另一任务提供证据，没有检验现代聊天模型的全部能力。
版本内部差异。固定v5的摘要与表2报告英法41.8，但§6.1正文写41.0。上表明确使用表2数字；这一差异应保留给读者核验，不能把两个数字混成同一条无条件结论。

BLEU衡量与参考译文的匹配，不是“人类理解能力”的统一刻度。测试集表2与开发集变体表3也不能直接比较成同一个排行榜。训练成本是作者估算的浮点运算量，并非对每个基线在同一台机器上重新计时。

Attention核心的n×n分数矩阵使序列变长时成本增长很快：n从100到1000，矩阵元素从1万到100万。这只比较显式分数矩阵，不是整模型耗时恰好增加100倍。投影和FFN也有成本：标准宽度d下，完整块还包含约O(nd²)的计算。不能把表1的Attention项直接当作整个Transformer复杂度。

原始模型是Encoder—Decoder：Encoder读源句，Decoder既有因果自注意力又有Cross-Attention。后来的decoder-only语言模型沿用因果注意力来处理一个token序列，并不是把原图右半边原封不动复制过去；通常没有独立源Encoder和读取它的Cross-Attention。GPT的发展是后续论文的主题，原论文没有提出今天的聊天对齐流程。可对照2018年GPT原论文§3.1与§4查看decoder-only架构的后续使用。

论文附录给出注意力可视化。它们能帮助观察信息混合，但注意力权重本身不构成对最终预测的可靠因果解释。本文对此采用谨慎的教学边界：读懂运算与读懂模型真正为何作答，是两个不同问题。后续研究Attention is not Explanation（2019）给出相关实验警示；其结论应按各自任务与模型范围理解。

用自己的话串起模型，再回到原文

Transformer先把token映射成向量并加入位置表示。每个注意力头通过学习的Q、K投影计算匹配，缩放并逐行softmax，再按权重汇总V。多头结果拼接并投影，接上残差、归一化和逐位置FFN。Encoder读取整个源句；Decoder对右移的目标前缀使用因果mask，再读取Encoder表示。训练时真实前缀已经给定，可以并行计算各位置；推理时继续使用刚生成的token，仍然逐步输出。原论文的贡献是架构和任务实验，不能直接扩展成对所有AI能力的保证。
Q、K、V是人工指定的语义字段吗？

不是。它们由输入表示乘不同的学习矩阵得到。检索类比解释计算角色，不能给向量坐标赋予固定可读语义。

为什么softmax按行，而不是整个矩阵一起？

每行代表一个查询对所有键的选择。每个查询各自需要一组总和为1的权重；整个矩阵一起归一化会让不同查询互相争抢同一个总和。

为什么mask允许对角线，却没有答案泄漏？

目标输入已右移：当前输入是前一个正确token，当前位置预测下一个。只有右移与因果mask一起才完整说明可见范围。

Attention与FFN各做什么？

Attention在不同位置之间混合信息；FFN对每个位置分别非线性加工。同一层FFN参数跨位置共享，多层间不共享。

并行训练是否意味着一次生成完整答案？

训练输入含整段真实前缀，可以一次计算各位置；推理没有未来token，下一步依赖已生成前缀，仍然自回归。

注意力权重0.9是否说明某个词对答案贡献90%？

不是。它只描述一个头、一个层、一次运行的V混合系数，不是最终输出的因果贡献比例。
