DeepSeek Balance 隐私政策

Last updated: 2026-09-21

一句话总结：本 App 不设账号、不含广告、不含统计 SDK。你的 API Key 与余额历史只保存在你自己的设备上，开发者无法访问。

1. 概述

DeepSeek Balance 是一个用于在 iPhone 与桌面上查看 DeepSeek API 账户余额与消费估算的工具。我们尽可能减少数据处理，所有余额历史都在你的设备本地保存。

2. 我们收集哪些信息

DeepSeek Balance 不会向开发者或任何第三方服务器上传数据，也不会收集下列信息：

  • 姓名、邮箱、电话等身份信息
  • 位置信息
  • 联系人、照片、麦克风、相机内容
  • 设备标识符、广告标识符（IDFA）
  • 使用行为分析、崩溃统计或埋点数据

3. API Key 如何处理

  • 你输入的 DeepSeek API Key 仅保存在本机 iOS Keychain 中。
  • App 发起查询时，会把该 Key 通过 HTTPS 发送给 DeepSeek 官方接口 api.deepseek.com，用于鉴权。这是该 Key 唯一的对外传输。
  • API Key 不会写入日志、不会写入普通文件、不会写入 App Group 共享容器，也不会发送给开发者或任何第三方。
  • 开发者没有能力读取你设备上的 Key，也无法访问你的 DeepSeek 账户。

4. 余额历史如何处理

每次成功查询余额后，App 会在设备本地记录一条余额快照（含时间、总余额、充值余额、赠送余额、币种），用于计算今日消费、日均消费与预计可用天数。

  • 这些记录保存在本机数据库中，保留最近 90 天，之后自动删除。
  • 不会上传到任何服务器，也不会通过 iCloud 同步。
  • “消费金额”是根据余额变化推算的估算值，不是 DeepSeek 官方账单数据。

5. 小组件与本地共享容器

为了让桌面小组件显示余额，App 会把最新一次成功获取的余额摘要写入设备上的 App Group 共享容器，供小组件读取。

  • 该共享容器只在你的设备本地，不涉及网络传输。
  • 其中包含余额、币种、更新时间与消费摘要。
  • 其中不包含你的 API Key。

6. 网络请求

App 只与你指定用途的服务端点通信：

  • https://api.deepseek.com/user/balance：查询账户余额。

App 不会访问其它任何域名，不加载网页，不做网页抓取。

7. 第三方服务

截至本隐私政策更新日期，DeepSeek Balance 未集成任何第三方广告、统计、崩溃收集或用户跟踪 SDK，也不包含任何第三方代码库。

8. 数据共享与出售

我们不收集你的数据，因此也不会出售、出租或共享你的数据给第三方。

9. 儿童隐私

DeepSeek Balance 是面向开发者的工具类 App，不面向儿童设计，也不会有意收集儿童个人信息。

10. 你的控制权

  • 在 App 的「设置」中随时删除本机保存的 API Key。
  • 删除 App 会一并移除设备上的余额历史与共享容器数据。
  • 你也可以随时在 DeepSeek 平台重新生成或吊销 API Key。

11. 联系方式

12. 政策更新

如果 DeepSeek Balance 的隐私实践发生变化，我们会在发布新版本时更新本隐私政策，并在此页面更新日期。

DeepSeek Balance 是独立开发的第三方工具，与 DeepSeek 官方没有关联，也未获得其认可或背书。“DeepSeek” 是其各自权利人的商标。
