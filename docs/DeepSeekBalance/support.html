DeepSeek Balance Support

DeepSeek Balance 让你不用打开 DeepSeek 开放平台，在 iPhone 桌面就能看到 API 剩余余额、今日消费与预计可用天数。

Last updated: 2026-09-21

快速开始

  1. 打开 App，点击「去配置」。
  2. 粘贴你的 DeepSeek API Key（以 sk- 开头）。
  3. 先点「测试连接」确认可用，再点「保存」。
  4. 回到首页即可看到余额；下拉或点「刷新」可重新查询。
  5. 长按桌面 → 左上角 + → 搜索「DeepSeek Balance」→ 添加小组件。

API Key 可在 DeepSeek 开放平台的 API Keys 页面创建。App 内不提供注册或登录，也不需要账号。

常见问题

为什么「今日估算消费」显示“数据积累中”？
消费是由余额变化推算的，计算一天的数据需要当天至少成功查询 2 次。首次使用当天只查一次时会显示“数据积累中”，而不是错误的 ¥0。
为什么「7 日平均」和「预计可用」一直显示“数据积累中”？
这两项需要至少 3 个完整自然日的历史数据才会给出结果。这是为了避免过早给出误导性的预测，连续使用几天后会自动出现。
为什么我今天刷新了好几次，今日消费还是没变？
5 分钟内的重复查询，如果余额没有变化，不会重复记录；余额一旦变化则会立刻记录。所以短时间内多次刷新不会产生新的数据点。
消费金额和 DeepSeek 后台对不上？
App 显示的是根据余额变化推算的估算值，不是官方账单。充值、赠送额度变化、退款或账务延迟都可能带来误差，请以 DeepSeek 官方账单为准。
提示「API Key 无效，请重新配置」？
请确认 Key 没有多余空格、没有被复制截断，并且仍然有效；也可以去 DeepSeek 平台重新生成一个 Key 后再试。
网络异常时余额会消失吗？
不会。查询失败时 App 会继续显示上一次成功获取的余额，并标注更新时间，网络恢复后自动更新。
桌面小组件一直是空的？
小组件读取的是 App 最近一次成功获取的余额。请先打开 App 完成配置并成功刷新一次，然后长按小组件选择「刷新」；iOS 对小组件刷新频率有系统级限制，不会实时更新。
换手机或重装 App 后数据还在吗？
余额历史只保存在本机，不会同步到 iCloud。重装或更换设备后历史会重新开始积累，需要重新配置 API Key。
API Key 会被上传吗？
不会。Key 只保存在本机 iOS Keychain，仅在查询余额时通过 HTTPS 发送给 DeepSeek 官方接口。详见隐私政策。
