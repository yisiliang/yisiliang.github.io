PhotoTimeFix Support

PhotoTimeFix 是一个用于根据文件名识别照片和视频时间，并批量修正系统相册创建时间的 iPhone 工具。所有扫描和修改都在设备本地完成。

PhotoTimeFix is an iPhone utility for identifying photo and video dates from file names and batch-fixing creation dates in the system photo library. All scanning and editing are performed locally on your device.

Last updated: 2026-05-23

如何使用

  1. 打开 PhotoTimeFix，并授予照片库访问权限。
  2. 等待 App 扫描照片和视频文件名。
  3. 查看识别出的文件名、当前时间和解析出的新时间。
  4. 勾选需要修正的项目。
  5. 点击批量修正，并在确认弹窗中确认。
  1. Open PhotoTimeFix and grant photo library access.
  2. Wait while the app scans photo and video file names.
  3. Review the recognized file name, current date, and parsed new date.
  4. Select the items you want to fix.
  5. Tap the batch fix action and confirm in the confirmation dialog.

常见问题

  • 如果列表为空，请确认照片库中存在支持的文件名格式。
  • 如果某些照片没有显示，通常表示文件名无法解析为明确时间。
  • 如果修改失败，请确认 App 拥有照片库读写权限。
  • 如果问题仍然存在，请发送邮件联系开发者，并尽量附上文件名样例、iPhone 型号和 iOS 版本。
  • If the list is empty, confirm that your photo library contains supported file name formats.
  • If some photos are not shown, their file names usually cannot be parsed into a clear timestamp.
  • If edits fail, confirm that the app has read/write access to your photo library.
  • If the issue persists, contact the developer by email and include sample file names, your iPhone model, and iOS version when possible.

联系与反馈

目前支持渠道为电子邮箱。来信时请尽量附上重现步骤、文件名样例、机型和 iOS 版本，这会帮助更快定位问题。

Support is provided by email. When possible, include reproduction steps, sample file names, your device model, and iOS version so the issue can be investigated more quickly.
